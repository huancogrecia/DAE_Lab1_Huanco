# DAE_Lab1_Huanco

Página web de la **Semana 1** del curso *Desarrollo de Aplicaciones Empresariales*, construida con **Django 6.1**.

## Contenido

- Objetivos de la semana
- Contenidos: aplicaciones empresariales, ERP/CRM/SCM/BI, arquitectura, ciclo de vida y herramientas
- Sistema de evaluación del curso
- Bibliografía recomendada

## Requisitos

- Python 3.10+
- Django 6.1 (`pip install django`)

## Ejecución

```bash
py manage.py migrate
py manage.py runserver
```

Abrir en el navegador: http://127.0.0.1:8000/
